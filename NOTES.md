# Workflow notes

## Repository and review environment

- Product repository: `Vishnuraj910/kodekommunity`.
- Default PR target: `main`.
- Local workspace: Kommunity.
- Review platform: GitHub.
- Available review surfaces: GitHub CLI and the connected GitHub app.
- Desired end state: the selected PR is ready to merge with no unresolved
  review conversations or pending actionable review comments.

## User terminology

- **Last PR:** the most recently updated open pull request in
  `Vishnuraj910/kodekommunity` targeting `main`.
- **Resolved:** code changes are verified, responses are posted, and the
  corresponding review conversations are marked resolved.
- **Ready to merge:** review conversations are resolved and required checks,
  approvals, and mergeability are green.
